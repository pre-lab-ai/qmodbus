# AIO2.0 BMS 与 PCS 设备 Modbus 规约及点表

> 文件：AIO2.0BMS与PCS设备Modbus规约及点表-20260115.pdf（整理重排版）

## 一、总则

1. 本规约以标准 Modicon Modbus 协议为基础，结合装置特点进行了适当扩充，采用 **Modbus RTU** 模式。
2. 物理层通讯口目前采用 **RS485**，建议采用屏蔽双绞线做通讯介质。
3. 链路工作模式：**8 个数据位，1 个停止位，无奇偶校验位**。
4. 通讯口波特率：**9600**。
5. **BMS 做主机，PCS 为从机**。

## 二、应用层报文基本格式

| 地址 | 功能码 | 数据 | 校验码 |
| --- | --- | --- | --- |
| 8 位 | 8 位 | N×8 位 | 16 位 |

### 设备地址域
地址范围 1～255，其中 **255 保留为主机对所有从机的广播地址**。一个通讯网络上的各装置地址不能重复，必须唯一。

### 功能码域

| 功能码（十六进制） | 含义 | 功能描述 |
| --- | --- | --- |
| 03H | 读寄存器 | 读取寄存器值 |
| 06H | 写单个寄存器 | 遥控 |
| 10H | 写多个寄存器 | 修改寄存器值 |

### 数据域
数据按寄存器地址排列，每个寄存器地址包含 **2 个字节**的数值；数值可以是模拟量数值、开关量状态、软压板状态、时间值、ASCII 字符串。

### 校验码域
采用标准 Modbus 16 位 CRC 校验，生成多项式 X16+X15+X2+1，**传输时低 8 位在前，高 8 位在后**；从报文首字节（地址域）到 CRC 码之前的所有字节参与计算。

- 响应时间：装置对主机查询的响应时间 ≤ 0.5 秒。

## 三、规约寄存器地址定义

> 按电池汇入 PCS 直流侧方式不同，寄存器地址定义有所不同。若干组电池同时工作（同时充放电，即 PCS 为一支路），寄存器地址定义如下表。本表按照富士康 AIO 项目进行改动。

### 表1：若干组电池同时工作（同时充放电，即 PCS 为一支路）

| 寄存器地址（HEX） | 字节数 | 数值类型 | 含义 | 单位 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 0x00 | 2 | 整数 | 工作状态信息 | — | 0x1111禁充，0x2222禁放，0x5555待机，0xAAAA跳机，0xBBBB正常，0xCCCC预警 |
| 0x01 | 2 | 整数 | 当前系统最大允许充电电流 | 0.1A | |
| 0x02 | 2 | 整数 | 当前系统最大允许放电电流 | 0.1A | |
| 0x03 | 2 | 整数 | 电池堆SOC | 0.1% | 0~1000 |
| 0x04 | 2 | 整数 | 电池堆可充电量 | 0.1kWh | 0~50000 |
| 0x05 | 2 | 整数 | 电池堆可放电量 | 0.1kWh | 0~50000 |
| 0x06 | 2 | 整数 | 电池堆总电压 | 0.1V | |
| 0x07 | 2 | 整数 | 电池堆总电流 | 0.1A | 正放负充 |
| 0x08 | 2 | 整数 | 电池堆单体最高SOC | 0.1% | 0~1000 |
| 0x09 | 2 | 整数 | 电池堆单体最低SOC | 0.1% | 0~1000 |
| 0x0A | 2 | 整数 | 电池堆单体最高电压 | 0.001V | |
| 0x0B | 2 | 整数 | 电池堆单体最低电压 | 0.001V | |
| 0x0C | 2 | 整数 | 电池堆单体最高温度 | 0.1℃ | |
| 0x0D | 2 | 整数 | 电池堆单体最低温度 | 0.1℃ | |
| 0x0E | 2 | 整数 | 当前系统最大允许充电功率 | 0.1kW | |
| 0x0F | 2 | 整数 | 当前系统最大允许放电功率 | 0.1kW | |

### 工作状态指令说明

| 状态码 | 说明 |
| --- | --- |
| 0x1111 | 表示电池不允许充电，此时 PCS 进入待机状态，不可充电，但可以放电。 |
| 0x2222 | 表示电池不允许放电，此时 PCS 进入待机状态，不可放电，但可以充电。 |
| 0x5555 | 表示电池系统告警，此时 PCS 执行待机指令，并无法执行任何充放电指令。 |
| 0xAAAA | 表示电池系统故障，此时 PCS 执行停机指令，并无法执行任何充放电指令，并断开交、直流接触器。 |
| 0xBBBB | 表示电池系统正常，此时 PCS 可执行任何指令。 |
| 0xCCCC | 表示电池发生预警，此时 PCS 仍可执行任何指令。 |

### 通讯示例

- **0x06 指令**：BMS 设置 PCS 工作状态：`01 06 00 00 BB BB + CRC`
  - "01" 表示 PCS 的 Modbus 地址，设备默认地址为 1；
  - "06" 表示 Modbus 设置指令；
  - "00 00" 为"工作状态"寄存器地址 0；
  - "BB BB" 表示工作模式为正常。
- **0x10 指令**：`01 10 00 00 00 01 02 BB BB + CRC`
  - "00 01" 表示需要设置的寄存器数目；
  - "02" 表示后面有效数据的字节数目。

## 四、BMS 与 PCS 通信说明

1. 在 BMS 与 PCS 通信过程中，**如果未收到数据的时间达到 10 秒，PCS 将产生"电池通讯故障"，并立即停机**。BMS 通过循环周期性地上报工作状态，以防储能逆变器因长时间未收到数据而停机，建议 1~3 秒上报 1 次。
2. 在 BMS 希望 PCS 待机或者停机时，首先选择通讯方式控制 PCS 的工作状态；如果 PCS 未执行，在一段时间后，BMS 要主动关断直流侧开关。
